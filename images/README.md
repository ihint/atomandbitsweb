# Photos

Use Ian's own photos, never stock. Each page shows a marked placeholder until its photo is here. To add one, save the file below and replace the matching `photo-placeholder` element with an `<img>` that has real alt text.

| File | Page | What it shows |
| --- | --- | --- |
| `ian-chattanooga.jpg` | Homepage hero | A relaxed, well-lit photo of Ian outdoors in Chattanooga (wide, about 2:1) |
| `life-chattanooga.jpg` | Homepage, Life in Chattanooga | One photo from home: the slopes, the woodshop or the chickens (about 4:3) |
| `about-skiing.jpg` | About photo row | On the slopes (square) |
| `about-woodshop.jpg` | About photo row | In the woodshop (square) |
| `about-chickens.jpg` | About photo row | The chickens (square) |
| `about-chess-or-books.jpg` | About photo row | A chessboard or a bookshelf (square) |

Example for the homepage hero:

```html
<img class="photo" src="/images/ian-chattanooga.jpg" alt="Ian Harman outdoors in Chattanooga" width="1300" height="650">
```

Keep each file under about 300 KB.
