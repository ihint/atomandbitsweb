# Photos

Use Ian's own photos, never stock. The placeholder blocks were removed. To add a photo, save the file below and put an `<img class="photo">` with real alt text on the page.

| File | Page | What it shows |
| --- | --- | --- |
| `ian-harman.jpg` | Homepage hero | In use. Ian in a navy jacket with snowy mountains behind him (portrait, 960 by 1341) |
| `life-chattanooga.jpg` | Homepage, Life in Chattanooga | One photo from home: the slopes, the woodshop or the chickens (about 4:3) |
| `about-skiing.jpg` | About photo row | On the slopes (square) |
| `about-woodshop.jpg` | About photo row | In the woodshop (square) |
| `about-chickens.jpg` | About photo row | The chickens (square) |
| `about-chess-or-books.jpg` | About photo row | A chessboard or a bookshelf (square) |

Example for a supporting page:

```html
<img class="photo" src="/images/about-woodshop.jpg" alt="Ian Harman in his woodshop" width="800" height="800">
```

Keep each file under about 300 KB.
